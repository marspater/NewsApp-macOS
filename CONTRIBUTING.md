# Contributing to News

Start with [README.md](README.md), [architecture and technology constraints](docs/ARCHITECTURE.md), [the Angelia name register](docs/ANGELIA.md), [PRIVACY.md](PRIVACY.md) and [SECURITY.md](SECURITY.md); for UI work, also the [design language](docs/design/DESIGN.md). These documents apply to every contributor. `AGENTS.md` contains instructions for coding agents only.

## Development

Use the existing native Swift/SwiftUI stack, keep changes focused, preserve user data and migrations, and treat feed/article input as untrusted. Maintain Swift 6 isolation and cancellation, deterministic taxonomy, accessibility, and the design language in [docs/design/DESIGN.md](docs/design/DESIGN.md): its tokens, components and Liquid Glass rules. Do not add cloud AI, telemetry or third-party models; the only models that ship are Apple's and CoreML models this project builds, measures and ships itself (#520).

Build on Apple silicon with Xcode 27 selected. The deployment target remains macOS 15; newer APIs require availability checks.

## Validation

Before tagging a release, run the [release checklist](docs/RELEASE_CHECKLIST.md): every gate item names a command or a manual check.

The current release simplification uses existing #102 labeled tune/English holdout regression inputs; the #409 comparison requires its original private replay export. Importance and overview review commands below remain opt-in historical audit tools, not new release requirements. Developing-story links (#314) ship in event overviews; their collector stays disabled, and the review commands below re-measure wrong links on a private library copy.

The app, the test runner, the harness apps, the native `NewsTests` bundle and the `NewsUITests` UI-testing bundle are the five targets of `News.xcodeproj` (#931), each over the synchronized `Sources/` folder (and `Tests/` for the runner, the harnesses and `NewsTests`, which compiles the root `Tests/*.swift` except `Runner.swift` plus `Tests/Native/`), so a new Swift file is compiled without being listed anywhere; `Sources/App/Main.swift` holds the app's `@main` and is the one file the harnesses leave out; the runner (Swift 5 language mode) also leaves out `NewsApp.swift` and the five window-level views, as it always did. The native `NewsTests` bundle compiles in Swift 6 language mode, like the app (#1070), so its build checks the same isolation rules; it compiles every file of `Sources/` except `Main.swift`, the `@main` entry point, so the app delegate and the window-level views are checked with it (`Tests/ReaderCommandNames.swift`, the runner's stand-in for `NewsApp.swift`, stays out of it). ## Pair review protocol (#551)

Pair decisions are reviewed on a copy of a library, never the live file. `--review-pairs` exports every stored decision with both headlines; the reviewer labels a sample and the numbers go into a dated file under `docs/audits/`. I delegate bulk review to an automated reviewer and spot-check; the audit says who labelled.

- **Labels.** `same` (one occurrence reported twice: paraphrases, updates, a toll that changed, a verbal reaction or direct consequence folded into its event), `related` (another act of the same story: the arrest after the fire, the condemnation after the attack, the protest after the vote), `different` (another story, or the same kind of occurrence elsewhere or at another time).
- **Tie rules.** A headline that names two acts follows the act it leads with. A live blog or explainer joins the event it covers. When the two headlines could be one occurrence or two and the leads do not settle it, the label is `different`: a missed link costs less than a wrong card.
- **Samples.** 200 `match` rows with reason `match`, 100 with reason `pairModel`, every `related-act` row, and 100 `vetoed` rows, drawn in a fixed pseudo-random order (sort by the SHA-256 of the two ids) so a rerun draws the same rows. A match or pair-model row labelled `different` is a false merge; the ceiling is 2% per sample.
- **Disagreements.** A spot-check that overturns a label is recorded in the audit with both labels and the reason; the overturned label is replaced and the sample is re-counted. Three overturned labels in twenty mean the whole sample is relabelled.
- **Receipts.** The CSV and the labelled copy stay outside the repository (`0700` directory, `0600` files); the audit records the copy's date, article count, matcher version and the SHA-256 of the labelled file.
- **Reviewed mistakes (#625).** Every labelled review sample (`sample_pairs.py --labels`) joins the training set at weight 5, and `--export-pairs` adds same-day negatives at weight 2 (two reports sharing a specific anchor within 36 h in different events of two or more members and different stories, with a hard conflict or a cosine below 0.58, #627); mined positives leave out links the pair model alone made; after each retrain a fresh sample of the new model's confirmations is labelled and joins the next round. The library holdout never enters training.
- **Reader verdicts (#552).** `--library-holdout` reads the copy's `event_inclusions` and `event_exclusions` before it clears the corrections and re-clusters: every "Same Event" pair must end up linked and every "Not the Same Event" pair apart, or the run prints the violated pairs and fails. No matcher or model change ships while a recorded verdict is violated; `--export-pairs` also turns the verdicts into weight-5 training rows.
- **Library holdout (#579).** `--review-pairs --holdout-candidates` draws the hard pairs of a library copy (borderline decisions scored ≥ 0.6, singletons sharing a specific anchor and a keyword with an event member within 36 h, pairs of active events sharing two terms); they are labelled the same way and saved as a JSON array of `{"a", "b", "label"}` beside the copy. `--library-holdout` re-clusters a temporary copy from scratch and reports two views (#627): strict event (pairs in one event: `same` is right, `related` and `different` are wrong, `different` also counted alone; recall on `same`) and story level (pairs whose events share a `story_id`: `same` and `related` are right, only `different` is a false merge; recall on `same` and `related`), and the share of recent stories in a multi-publisher event. A matcher or pair-model change ships when, against the shipped model, strict `same` does not fall and strict `different` does not rise, story-level `different` does not rise and story recall rises, and the tune replay and the authored corpus are unchanged (my rule, #574; "does not rise" since 10 November 2026, #737: a set without a story-level `different` cannot show a fall); the result and the file's SHA-256 go into the slice's PR. The old 49-article holdout stays sealed.

## Remove legacy test preferences (#311)

Older test runs left migration-test preferences behind. The following one-time cleanup previews only files named `com.marspater.news.test.<UUID>.plist` in the user and app-container preferences directories. It never selects `com.marspater.news.plist` or other settings. Run it with the tests stopped; set `delete = True` only after reviewing the preview to remove those test files.

```sh
python3 - <<'PY'
from pathlib import Path
import re

delete = False
pattern = re.compile(r"com\.marspater\.news\.test\.[0-9A-Fa-f]{8}(?:-[0-9A-Fa-f]{4}){3}-[0-9A-Fa-f]{12}\.plist")
directories = [
    Path.home() / "Library/Preferences",
    Path.home() / "Library/Containers/com.marspater.news/Data/Library/Preferences",
]
for directory in directories:
    if not directory.is_dir():
        continue
    for path in sorted(directory.iterdir()):
        if pattern.fullmatch(path.name) and path.is_file() and not path.is_symlink():
            print(path)
            if delete:
                path.unlink()
PY
```
