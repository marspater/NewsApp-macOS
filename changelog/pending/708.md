- Hybrid search fuses SQLite FTS5 lexical matching and on-device natural language semantic similarity (`article_embeddings`) using Reciprocal Rank Fusion ($k = 60$), surfacing conceptually relevant stories even when headlines lack exact keywords.
- Mute rules and filter tokens (`is:unread`, `source:`, `category:`) are strictly applied across both lexical and semantic ranking arms.
- Lexical search matches display FTS5 keyword snippet highlights, while semantic-only hits preserve story deks without fabricating snippets.
- Pure operator queries bypass vector embedding and run chronologically.
