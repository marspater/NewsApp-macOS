# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues, discussions, or pull requests.**

### How to submit:
1. Navigate to the **[Security](https://github.com/marspater/NewsApp-macOS/security)** tab of this repository.
2. Click **Advisories** on the left menu.
3. Click **Report a vulnerability** to open a private advisory draft.
4. Include:
   - A clear description of the vulnerability.
   - Exact steps or proof-of-concept to reproduce.
   - Potential impact and affected macOS versions.

### What to expect:
- **Initial Response:** Within 48 hours acknowledging receipt.
- **Triage & Patch:** We will coordinate a fix privately and credit you upon release of the security advisory.
