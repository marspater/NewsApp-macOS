## Core Objectives
1. **Native macOS (Apple Silicon):** Built using SwiftUI/AppKit for maximum performance and native look.
2. **Cinematic Design:** Heavily inspired by Glassmorphism and modern Apple design language.
3. **Ad-Free Content:** Using a custom extraction engine to strip all ads and trackers.
4. **Smart Filtering:** Utilizing sophisticated algorithms or local MLX models to curate content based on interests.
5. **Intelligent Notifications:** Only bothering you with what truly matters.
