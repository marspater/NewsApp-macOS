## Where the first seconds went

A shard's wall time exceeded the sum of its tests by about 6 s, at low CPU: shard 3 of 4 took 9.1 s with 2.3 s of tests and 2.4 s of user time. `sample` on a stalled process shows `FeedManager.clusterEventsInBackground` → `EventClusterer.run` → `SentenceEmbedder.shared` in its one-time initialization, on `com.apple.anef` queues: the Neural Engine programs loading cold.

Each job ran its own copy of the runner, named after the job, and Core ML keeps its compiled models in a cache named after the executable. So every process loaded cold: 2.9 s for the first model-using test alone, about 6 s with others in parallel. Under one name the same shard ran sequentially in 5.40 s, 2.39 s, 2.38 s.

`--warm-models` costs 4.66 s cold and 0.22 s warm.

## What the split already takes

`StoryCorpus.run` runs once per lane today and will run once per pool after the split of `Tests/NewsTests.swift`, so that saving is not this change's. Its measured cost: about 8 s on a lane that uses no model (`NewsTests-sockets`, cold, 11 s to 3 s without it), nothing on the model-using lanes, where the load moved into their first model test, and no job-time difference with warm caches. The 1 s and 3 s after-figures for lanes that use no model therefore overlap with the split. The longest job and the whole-run time are set by model-using lanes, so those savings stand; the sum of job times overlaps by up to the sockets lane's 8 s.

## The change

`test.sh` runs `--warm-models` once when the pool has more than one job, then every job runs the same binary. The race the per-job copies guarded against, two processes compiling the same model under one name (seen on CI), cannot happen for `SentenceEmbedder.shared` and `PairScorer.shared`, whose compile finishes before the pool starts. A single job skips the warm-up, so a one-atom commit hook pays nothing.

Limits of this change:

- A test that compiles a new model configuration in two lanes at once would hit that race. No configuration a test builds itself does so today; none needs warming:

  | Construction | Configuration | Runs in the pool |
  | --- | --- | --- |
  | `PairScorer()`, `Tests/EventEmbeddingTests.swift:92` | the warmed default | any lane is safe |
  | `SentenceEmbedder()`, `Tests/NewsTests.swift:2848` | the warmed default | any lane is safe |
  | `SentenceEmbedder(modelURL:vocabURL:)`, `Tests/EventEmbeddingTests.swift:335` | the warmed default when the model is present, otherwise no load | any lane is safe |
  | `SentenceEmbedder(modelURL:vocabURL:)`, `Tests/NewsTests.swift:24807` | corrupt fixture, load fails | no compile |
  | `MLModel(contentsOf:)`, `.all`, `Tests/EventEmbeddingTests.swift:398` | not warmed | one process, through `testEventEmbeddingIntegration`; keep it in one atom |
  | `SentenceEmbedder(modelURL:computeUnits:)` and `MLModel(contentsOf:)`, `Tests/EventEmbeddingTests.swift:878`, `:907` | not warmed | no: `reportComputePlacement`, a targeted mode |
  | `PairScorer(modelURL:)`, `Tests/StoryCorpus.swift:211`, `:231` | candidate models | no: evaluation variables only |
- Jobs now share the name's standard defaults and URL storage. In `Tests/`, `UserDefaults.standard` is read only by the `NewBriefingIntent` check right after that intent writes the same keys, and no other job writes them. A future test asserting that a standard-defaults key is absent would be order dependent. Sixteen pools passed on this path.
- `script/ci_testsuite.sh` has its own loop and is unchanged. CI timings were not measured here.

## Tried and rejected

- **Skipping the corpus replay outside the first shard.** With cold caches the load only moved into the next model-using test. With warm caches, three alternating runs each showed no difference in any job. Dropped.
- **Cloning a warm cache into each job's name.** No effect over two alternating runs each: the cache does not transfer across executable names.
- **CPU-only models.** Longest job 16 s, but `Single boundary text 0: cosine 0.99983` fails the `>= 0.9999` fidelity assertion, and the corpus tests would stop running on the shipped placement. Not acceptable.
